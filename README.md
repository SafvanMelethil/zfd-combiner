# ZFD Combiner

Combine numbered `.txt` files (e.g. `1-50.txt` + `51-100.txt` → `1-100.txt`).

- The first file keeps its header; the matching header line is removed from every other file.
- Every data line is kept. A line-count check confirms nothing is missing before you download.
- Runs fully in the browser — files never leave your computer.

Open `index.html`, or enable GitHub Pages (Settings → Pages → Deploy from branch → `main` / root).
